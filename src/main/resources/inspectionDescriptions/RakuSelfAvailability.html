Reports use of self where no invocant exists, or where the object is not yet fully built.

There is no invocant outside a method, so self and the $. form have nothing to refer to. Separately, inside BUILD and default-value expressions the object is only partially constructed: a virtual method call such as $.name may dispatch to an override that reads attributes not yet initialised. Use direct attribute access, $!name, in that case. 


sub helper() {
    say self;              # No invocant is available here
}

class Person {
    has $.name;
    submethod BUILD() {
        say $.name;        # Virtual method calls are not allowed on partially constructed objects
    }
}

# Correct
class Person {
    has $.name;
    submethod BUILD() {
        say $!name;
    }
}
