Reports use of a type that another file in the project declares, but that is not imported here.

A global (our-scoped) class, role, enum or subset declared in one module of the project is only visible to another file after a use of the module that provides it. The quick fix adds the missing use statement; when several project modules declare the type, one fix is offered per candidate. Type names no project file provides are left unreported, since they may arrive through require, indirect lookups, or other means static analysis cannot see. 


# lib/Amazing/Mazes/Renderer.rakumod
unit class Amazing::Mazes::Renderer;

# lib/Amazing/Mazes/Maze.rakumod
unit role Amazing::Mazes::Maze;
method render(Amazing::Mazes::Renderer $renderer) { }   # Type is not imported

# Correct
use Amazing::Mazes::Renderer;
unit role Amazing::Mazes::Maze;
method render(Amazing::Mazes::Renderer $renderer) { }
