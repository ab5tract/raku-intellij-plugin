Reports a hard-coded reference to the raku executable in a string.

A bare raku, rakudo or perl6 assumes a particular name on a particular platform and a particular PATH. $*EXECUTABLE is the interpreter currently running, so it stays correct across operating systems, across installs, and when several Rakudo versions are present. 


my $proc = run 'raku', '-e', 'say 42';

# Correct
my $proc = run $*EXECUTABLE.absolute(), '-e', 'say 42';
