Reports an @ or % variable that is not last in a list assignment.

List assignment fills its targets left to right, and an array or hash is greedy: it takes every remaining value, leaving the variables after it empty. That is almost never what a multi-variable declaration is trying to express. Bind with := to destructure positionally instead. 


my (@first, $second) = 1, 2, 3;   # Array slurps everything from assignment
                                  # @first is [1, 2, 3]; $second is Any

# Correct
my (@first, $second) := \(1, 2), 3;
