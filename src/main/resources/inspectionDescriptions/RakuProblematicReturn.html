Reports a return that cannot do what it appears to.

return unwinds to the enclosing routine. A start, react, supply or whenever block runs on its own schedule, quite possibly on another thread and long after the routine that set it up has returned, so there is no frame left to unwind to. This is not caught at compile time and it does not fail gracefully: reaching such a return aborts the process with MoarVM panic: Did not find expected unwind target frame.

Let the block's last expression be its value instead. A return outside any routine at all is also reported; that one dies cleanly with Attempt to return outside of any Routine. 


sub fetch() {
    await start {
        return get-data();      # Cannot use return to produce a result in a start block
    }                           # ... MoarVM panic when this actually runs
}

# Correct
sub fetch() {
    await start {
        get-data();
    }
}
