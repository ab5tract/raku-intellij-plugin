Reports .grep(...).first, which can be written as a single .first.

Both forms return the first matching element, but .grep is specified to produce a lazy sequence of all matches, whereas .first stops at the one it needs. The combined form is shorter and states the intent directly.

Only reported when the .first call has no arguments of its own and .grep has exactly one.


my $found = @items.grep(*.active).first;

# Correct
my $found = @items.first(*.active);
