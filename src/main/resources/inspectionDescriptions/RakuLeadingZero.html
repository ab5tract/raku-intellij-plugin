Reports an integer literal with a leading zero.

Unlike C, Perl or Python 2, a leading zero does not make a literal octal in Raku — 0755 is simply seven hundred and fifty-five. Code carried over from another language will silently compute the wrong number. Raku's octal prefix is 0o. 


my $mode = 0755;      # Decimal 755, not octal

# Correct
my $mode = 0o755;     # Decimal 493
