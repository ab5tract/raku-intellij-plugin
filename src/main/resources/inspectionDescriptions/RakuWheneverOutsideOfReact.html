Reports a whenever block outside react or supply.

whenever subscribes to an asynchronous source, and needs an enclosing react or supply block to own that subscription and keep it alive. On its own there is nothing to attach to. 


whenever Supply.interval(1) {     # A whenever must be within a supply or react block
    .say;
}

# Correct
react {
    whenever Supply.interval(1) {
        .say;
    }
}
