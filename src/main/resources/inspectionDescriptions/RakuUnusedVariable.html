Reports a variable, attribute or parameter that is declared but never read.

Usually a leftover from an edit, or a typo where the use refers to a slightly different name. Where the declaration can be removed safely — a standalone variable or attribute, as opposed to a parameter or one name in a multi-variable declaration — a quick fix offers to delete it. To keep a parameter deliberately unused, name it $. 


sub process(@items, $unused) {   # Unused parameter
    my $count = 0;               # Unused variable
    @items.map(*.value);
}

# Correct
sub process(@items, $) {
    @items.map(*.value);
}
