Reports is or does on a module or package.

Inheritance and role composition are features of the object system, and only class and role participate in it. A module or package is a namespace: it has no method resolution order to extend and nothing to compose into. 


role Loggable { }

module Utils does Loggable { }   # module cannot compose a role
package Tools is Utils { }       # package cannot inherit a class

# Correct
class Utils does Loggable { }
