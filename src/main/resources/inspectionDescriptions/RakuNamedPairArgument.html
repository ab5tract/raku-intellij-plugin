Reports a fat-arrow pair that has a shorter colon-pair spelling.

Three cases collapse: a True value becomes :key, a False value becomes :!key, and a value that is a variable of the same name becomes :$key. All are exactly equivalent, and the short forms are the conventional way to write them. 


run 'curl', out => True, err => False;
my $verbose = True;
report(verbose => $verbose);

# Correct
run 'curl', :out, :!err;
report(:$verbose);
