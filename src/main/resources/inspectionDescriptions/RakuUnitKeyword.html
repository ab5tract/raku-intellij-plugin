Reports mismatched use of the unit keyword on a package declaration.

A declaration has two forms. The block form, class C { ... }, encloses its body in braces. The semicolon form, unit class C;, takes the rest of the file as its body and requires the unit keyword. Using a semicolon without unit, or unit together with a block, does not compile. 


class C;              # Semicolon form of 'class' without 'unit' is not supported

unit class D { }      # Cannot use 'unit' with block form of declaration

# Correct
unit class C;

class D { }
