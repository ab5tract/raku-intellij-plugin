Reports a hyphen used inside a regex character class.

Raku does not spell ranges with - the way PCRE does — the range operator inside a character class is .., and Rakudo rejects a bare hyphen between two characters outright: Unsupported use of - as character range. A pattern carried over from another language therefore fails to compile rather than quietly matching the wrong thing.

To match a literal hyphen, escape it or place it first or last in the class. Class subtraction is a separate construct and uses - between two bracketed groups, not between characters. 


/ <[ a-z ]> /              # Unsupported use of - as character range

# Correct
/ <[ a..z ]> /             # Range
/ <[ az- ]> /              # Literal hyphen, last in the class
/ <[ a..z ] - [ aeiou ]> / # Subtraction: consonants
