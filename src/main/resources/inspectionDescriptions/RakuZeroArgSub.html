Reports a subroutine that takes no parameters and could be declared as a term.

A parameterless sub still has to be called with empty parentheses, because a bare mention of its name is a reference to the routine rather than a call. Declaring it term:<name> lets it be used as a plain word, which reads better for something that is conceptually a constant or a generator.

This is informational: a parameterless sub is perfectly correct, and MAIN is never reported.


sub answer() { 42 }
say answer();

# Correct
sub term:<answer> { 42 }
say answer;
