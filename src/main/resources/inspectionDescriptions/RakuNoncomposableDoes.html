Reports does applied to a class.

does composes a role. A class is inherited from, not composed, so the relationship has to be spelled is. This is easy to get wrong when a role is later refactored into a class and its consumers are not updated. 


class Base { }
class Derived does Base { }    # Class cannot compose a class
role  Mixin   does Base { }    # Role cannot compose a class

# Correct
class Derived is Base { }
