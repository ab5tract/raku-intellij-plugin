Reports a class that composes a role without implementing every method the role requires.

A role method declared with the yada body { ... } is a stub: it demands that the composing class supply an implementation, and composition fails at compile time otherwise. An attribute's generated accessor, or a handles delegation, satisfies the requirement just as a method does.

Private (!-twigil) role methods are not composition requirements and are never reported.


role Drawable {
    method draw { ... }
}

class Circle does Drawable { }   # Composed roles require to implement methods: draw

# Correct
class Circle does Drawable {
    method draw { say 'O' }
}
