Reports a regex with an empty body.

An empty regex would match the empty string at every position, which is never useful and is rejected by Rakudo. It normally means a pattern was deleted, or a token or rule was stubbed out and never filled in. 


my $re = //;              # Empty regex is not allowed

grammar G {
    token name { }        # Empty regex is not allowed
}

# Correct
grammar G {
    token name { \w+ }
}
