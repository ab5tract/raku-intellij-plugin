Reports parameter declarations that are contradictory or redundant.

Five cases, all of them signature defaults being restated or fought:

  • an optional positional parameter placed after a named one;
  • ? on a named parameter — nameds are optional already;
  • ! on a parameter that has a default value — it cannot be both;
  • ! on a positional parameter — positionals are required already;
  • ? on a parameter that has a default — a default already implies optional.

sub f($a!) { }            # `!` is redundant, positionals are required by default
sub g(:$b?) { }           # `?` is redundant, nameds are optional by default
sub h($c! = 10) { }       # Has a default value and so cannot be required
sub i(:$d, $e?) { }       # Cannot put an optional parameter after a named parameter

# Correct
sub f($a) { }
sub g(:$b) { }
sub h($c = 10) { }
sub i($e?, :$d) { }
