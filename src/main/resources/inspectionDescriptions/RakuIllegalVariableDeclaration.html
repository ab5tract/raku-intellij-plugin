Reports a declaration of a name that Raku reserves and populates itself.

Regex match variables — positional $0, $1… and named $<name> — are elements of the match object $/ and cannot be declared. Neither can a contextualizer such as $( ) or @( ), which is an operator rather than a name. 


my $<foo>;      # Cannot declare a regex named match variable
my $0;          # Cannot declare a regex positional match variable
my $()          # Cannot declare a contextualizer

# Correct: match variables are already available after a match
if $text ~~ / $<foo> = \w+ / {
    say $<foo>;
}
