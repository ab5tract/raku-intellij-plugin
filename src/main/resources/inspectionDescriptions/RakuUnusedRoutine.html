Reports a subroutine or private method with no callers.

The search is scoped to where the routine could be reached from: a lexical scope for a my/our sub, the declaring class for a private method. A routine that is exported, or that Raku calls for you — MAIN, USAGE, EXPORT — is never reported.

Quick fixes offer to remove the routine, or (for a subroutine) to mark it is export if it was meant to be part of the module's interface. 


sub helper() { }         # Unused subroutine

class C {
    method !unused() { } # Unused private method
}

# Correct
sub helper() is export { }
