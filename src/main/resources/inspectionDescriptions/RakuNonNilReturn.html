Reports a value produced by a routine whose declared return type is Nil.

--> Nil is a promise that the routine yields nothing useful, and Raku holds you to it in two different ways. An explicit return with an argument is a compile error — No return arguments allowed when return value Nil is already specified in the signature. A value arrived at implicitly, as the routine's last expression, is instead coerced away: the caller always receives Nil, so the expression is computed and discarded.

The second case is the one worth catching. It compiles, and the routine reads as though it returns something, but no caller can ever observe it. 


sub log-it($msg --> Nil) {
    say $msg;
    $msg;              # A value is returned from subroutine returning Nil
}                      # ... and the caller still gets Nil

# Correct
sub log-it($msg --> Nil) {
    say $msg;
}
