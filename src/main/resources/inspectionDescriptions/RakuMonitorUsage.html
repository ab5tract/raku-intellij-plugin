Reports a monitor declaration without OO::Monitors in scope.

monitor is not core Raku syntax; it is a package declarator added by the OO::Monitors module, which also supplies the method-level locking that makes a monitor useful. Without the import the declaration will not compile. 


monitor Counter {      # Cannot create package of 'monitor' type without OO::Monitors imported into scope
    has $!count = 0;
}

# Correct
use OO::Monitors;

monitor Counter {
    has $!count = 0;
}
