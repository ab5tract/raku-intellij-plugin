Reports is export on a my-scoped variable.

Exporting means installing a symbol into the importer's lexical scope, which requires the symbol to be visible in the package to begin with. my is lexical to the declaring block, so there is nothing for the export to publish. Use our — or, for a constant, our constant. 


unit module Config;

my $DEFAULT-PORT is export = 8080;    # `my` scoped variable cannot be exported

# Correct
our $DEFAULT-PORT is export = 8080;
