Reports an assignment whose target cannot be assigned to.

Raku containers are only mutable when something makes them so. Literals, constants, routine declarations and read-only parameters (the default binding for a parameter, absent is copy, is rw or is raw) have no container to write through, so an assignment to one fails at runtime.

The message names what was found, e.g. Cannot assign to a readonly parameter.


sub scale($factor) {
    $factor = $factor * 2;   # Cannot assign to a readonly parameter
}

my constant LIMIT = 10;
LIMIT = 20;                  # Cannot assign to a constant

# Correct
sub scale($factor is copy) {
    $factor = $factor * 2;
}
