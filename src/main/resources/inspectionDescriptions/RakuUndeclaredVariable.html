Reports use of a variable with no declaration in scope.

Raku requires declaration before use, and lexical scoping means a my further down the file does not help code above it — that case is reported distinctly as not declared in this scope yet. Also covers $=finish in a file with no =finish section, and use of an implicit variable such as $_ in a block whose signature does not declare it. 


say $total;                 # Variable $total is not declared

say $count;                 # Variable $count is not declared in this scope yet
my $count = 0;

# Correct
my $total = 0;
say $total;
