Reports EVAL of a string containing interpolation, without the required pragma.

Evaluating an interpolated string means running code assembled at runtime, so Raku refuses unless the file opts in with use MONKEY-SEE-NO-EVAL (or use MONKEY). The pragma is a deliberate speed bump: whatever is interpolated becomes executable, so it must be trusted. 


my $expr = get-user-input();
EVAL "1 + $expr";        # Cannot EVAL interpolated expression without MONKEY-SEE-NO-EVAL pragma

# Correct
use MONKEY-SEE-NO-EVAL;
EVAL "1 + $expr";
