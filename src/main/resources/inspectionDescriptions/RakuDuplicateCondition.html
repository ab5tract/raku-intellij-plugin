Reports a branch whose condition already appeared earlier in the same chain.

A repeated condition is dead code: the earlier branch always wins, so the later one can never run. Conditions are compared after normalisation, so if/elsif are treated alike and commutative infix operators are matched regardless of operand order. Usually it means a copy-pasted branch whose condition was never edited. 


if $x == 1 {
    do-one();
}
elsif $x == 2 {
    do-two();
}
elsif $x == 1 {      # An identical condition appears in a previous branch
    never-reached();
}
