Reports a call to a private method that the type does not declare.

Private methods are not virtual and are not inherited: self!foo resolves against the current class only, at compile time, so a name that is not declared there is an error rather than a dispatch failure. A subroutine name may not begin with ! at all, which is reported separately. 


class C {
    method run() {
        self!helper();     # Private method !helper is used, but not declared
    }
}

# Correct
class C {
    method run() {
        self!helper();
    }
    method !helper() { }
}
