Reports a used module that cannot be found, or that is declared inconsistently.

Four distinct situations, and the message says which:

  • the module is not installed for the current Raku;
  • it is listed in META6.json depends but is not installed;
  • it is used but missing from META6.json depends;
  • it cannot be found in the ecosystem at all — typically a typo in the name.

Pragmas and modules that ship with Rakudo are not reported. Quick fixes offer to install the module, add it to META6.json, or create it locally.


use Cro::HTTP::Router;    # Module Cro::HTTP::Router is not installed for current Raku

use JSON::Fasst;          # Cannot find JSON::Fasst in the ecosystem
