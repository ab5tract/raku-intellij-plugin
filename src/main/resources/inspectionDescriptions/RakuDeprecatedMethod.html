Reports a call to a method its author has marked deprecated.

Deprecation comes from the is DEPRECATED trait, either in a module you use or in the Rakudo core setting. When the trait carries a replacement, the message names it. 


class Legacy {
    method old-name() is DEPRECATED('new-name') { }
    method new-name() { }
}

Legacy.old-name();   # method 'old-name' is deprecated ... use new-name

say 42.perl;         # method 'perl' is deprecated ... use raku
