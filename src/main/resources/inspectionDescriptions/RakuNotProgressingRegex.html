Reports a + or * quantifier on an atom that can match nothing.

If the quantified atom succeeds while consuming no characters, the engine can repeat it forever without advancing — the match hangs rather than fails. This usually comes from nesting one quantifier inside another, where the inner one already permits zero matches. 


/ [ \d* ]+ /       # Quantified expression may not progress, leading to a hang

# Correct
/ \d+ /
/ [ \d+ ]+ /
