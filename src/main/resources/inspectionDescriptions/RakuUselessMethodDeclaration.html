Reports a has-scoped method declared where it can never be called.

Methods need an object to be invoked on. A module or package is a namespace with no instances and no method resolution order, and a method declared at file scope has no invocant at all, so in both cases the declaration is inert — Rakudo says as much itself: Useless declaration of a has-scoped method in module.

Either make the enclosing declarator a class or role, or, if the routine really is just a helper, declare it my method (callable on an explicit invocant within the lexical scope) or an ordinary sub. 


method orphan() { }          # Useless declaration of a method outside of any package

module Utils {
    method helper() { }      # Useless declaration of a method in a module
}

# Correct
class Utils {
    method helper() { }
}

module Utils {
    sub helper() { }
}
