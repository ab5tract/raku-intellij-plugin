Reports a range starting at zero that the ^ operator expresses more directly.

^N is shorthand for 0..^N — zero up to but excluding N — which is the usual shape for indexing and counting. Writing the lower bound out, or subtracting one from the upper bound, is noise. 


for 0..^10 { }
for 0..$n-1 { }
my @indices = 0..^@items.elems;

# Correct
for ^10 { }
for ^$n { }
my @indices = ^@items.elems;
